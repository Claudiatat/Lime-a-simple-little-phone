常见问题
怎么接入 DeepSeek / Kimi / 硅基流动？
在"设置 → API 预设"里选中服务商，点击"编辑"填入你的 API 密钥即可。内置 DeepSeek、Kimi、硅基流动三个预设，也可以自定义任意 OpenAI 兼容接口。
时间感知是什么？
开启后，每次对话会告诉 AI 当前的现实日期时间，ta 能感受到真实时间流逝；关闭后 AI 只知道剧情世界里的时间（由人设和世界书设定）。
ta 和世界书怎么配合？
创建/编辑 ta 时可以勾选绑定"局部"世界书；"全局"世界书自动对所有人设生效。
